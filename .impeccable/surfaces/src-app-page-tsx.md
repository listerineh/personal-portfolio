# Surface brief: home (and site shell)

Scope: home (`src/app/page.tsx`) plus the shared shell (header, footer) that every route inherits. Visitor mode: Experience. The work leads from the first viewport.

Audience: a balanced mix of hiring managers, founders, and developers (see PRODUCT.md). About half arrive on mobile, so mobile-first from the first commit: every composition is designed at 360px first and expanded upward.

Action: explore the work (projects, posts, roles). Contact, CV, and newsletter are secondary.

Constraints: primary color stays amber #D97706 (user decision, 2026-10-15). Content unchanged except hero and metadata copy, which may move to "full-stack + applied AI". Music lives only in about and /why.

## Direction contract

THESIS (Lumen, replaced Sala on 2026-10-18 at the owner's request): Apple-like restraint, minimal but never boring. Neutral plain/tint grounds that alternate, rounded panels, Geist with tightening tracking, amber #D97706 as the only accent, spring motion tied to scroll.

Home order (owner decision): hero → experience → projects → skills → blog → contact.

- Hero: full first screen; name + "I build {rotating noun}" in amber; a decorative deck of agent/code/deploy windows with pointer parallax; ambient light (halos, dot grid, amber spotlight).
- Experience: every role in a RoleExplorer (timeline + detail); /experience redirects here.
- Projects: carousel of rounded cards with 4:3 product shots generated by scripts/generate-project-images.js.
- Skills: two marquee rows in opposite directions with a category filter.
- Blog: front-page layout (lead story + compact list).
- Contact: one lit card.

Refuses: square gallery framing, mono-as-costume, identical static card grids as the only presentation, neon/glow, a second accent.

See DESIGN.md for tokens and the component map.
